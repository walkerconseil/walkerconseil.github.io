Production Runbook Summary

From dark capability to one enabled Site.

01

Confirm authority

Name exact refs, operators, target Sites, acceptance and rollback owners.

Continue whenEvery mutation boundary is explicitly authorised.
02

Inventory and pre-provision

Pair every API/Hive deployment, create the disabled Hive Vault record and confirm both Git stanzas.

Continue whenEvery application, field and target revision is unambiguous.
03

Prove rendering

Measure live Argo, AVP and Helm, then run static and exact-live candidate renders.

Continue whenEvery render passes with no unresolved placeholder.
04

Deploy capability dark

Propagate generic wiring and reconcile API before Hive while all Sites remain disabled.

Continue whenHealth and fail-closed admission checks pass.
05

Establish trust

Private key material goes to Hive Vault; only public trust goes to Converlens.

Continue whenIssuer, origin and public key validate without secret exposure.
06

Activate the cluster

Write the matched Hive key pair first, then merge API and Hive identity configuration together.

Required orderVault before Git. API before Hive.
07

Enable one Site and accept

Enable one audited Site entitlement, then prove the intended destination and fail-closed cases.

Complete whenThe Site passes Protocol A and controlled acceptance.
If anything goes wrong: disable the affected Site first, wait for admitted work to drain, and treat cluster disablement or offboarding as separate authorised actions.
