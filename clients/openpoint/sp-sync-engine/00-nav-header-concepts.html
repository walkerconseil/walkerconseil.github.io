Design exploration, not part of the shipped pack

Header and nav concepts for the consolidated structure

Five options for the pack-wide header now that the plan is a landing page, four numbered content pages, and a Get Started page. Each row below is a real rendered header using the live shared.css tokens, not a description of one. Concept 0 is today's exact style, extended to the new item count, as a reference point for what changes in each option after it.

Concept 0

Baseline, no differentiation

Today's exact treatment (numbered mono chips, brand wordmark on the left) with the new item set dropped in as-is. Get Started reads as just another page in the list, not a call to action. Useful as a control to compare the other options against.

Concept 1

Icon home, filled CTA pill

The wordmark is replaced with a small house icon (the pack name already lives in the browser tab and the landing page itself, so it does not need repeating in every header). Get Started becomes a solid clay pill, the only filled shape in the bar, so it reads as the one actionable item among four informational links.

Concept 2

Wordmark home, outlined CTA behind a divider

Keeps the familiar wordmark as the home link (clickable now, it was a static label before). A thin vertical divider separates the four content links from Get Started, so the CTA reads as its own zone rather than a fifth item in the list. The outline (rather than a fill) keeps it a step quieter than concept 1, still distinct, not shouting.

Concept 3

Compact icon home, CTA with a directional glyph, pushed hard right

The most minimal home treatment (icon only, no border, closer to a favicon-style mark) frees up room so Get Started can sit with real breathing room on the far right, plus a small arrow to read as "go do this" rather than "read this page". Best option if Get Started should feel closer to a product CTA than a documentation tab.

Concept 4

Two-tier header

Splits the bar into two rows: a slim top row with the home icon, wordmark and the Get Started CTA always pinned top-right, and a second row underneath for the four content links. Worth testing if the single-row bar ever feels crowded once real labels (rather than these short placeholders) are in place, at the cost of a taller sticky header overall.
