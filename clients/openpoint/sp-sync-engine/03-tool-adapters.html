Tool Adapters

From one-off import to durable connector.

Nine root adapters persist Social Point source identity and support repeatable reconciliation of an existing Converlens destination. Selected-tool sync is initiated explicitly, then runs as a durable queued operation while Social Point remains authoritative for the activity itself.

01What The Adapter Programme Adds

The change is continuity. The legacy importer creates a destination; the adapter programme keeps a known source identity and can reconcile that destination again through the same controlled contracts.

One-off importer

Create a new destination

A user-initiated import runs through a mixed-purpose flow and treats the destination as a fresh build.

>
Durable connector

Reconcile a known destination

An explicit command starts a durable operation against persisted source identity and owned native state.

Nine rootsOne catalogue recognises nine selectable adapter types.
Tool contractsEach source validates and preserves the semantics it owns.
Explicit plansPure planners express create, update, remove and preserve decisions.
Durable workPersisted operation state carries retries, warnings and outcomes.
Current trigger: linking queues an initial metadata refresh. Selected-tool data reconciliation is initiated through an explicit command, then executed as durable queued work.

03One Adapter Anatomy

Every root adapter uses the same five-part implementation shape. Tool semantics vary; the route from typed source evidence to an explicit native plan does not.

Planner invariant: represented source state plus an already loaded destination projection becomes an explicit create, update, remove or preserve plan.

05Where Source Semantics Differ

A shared programme does not erase source meaning. Each adapter preserves the distinctions analysis needs before its canonical submission commands reach the shared kernel.

Versioned / Form App

Represent the current definition exactly

Analytical blocks come from the represented current_form definition. Unsupported or hidden whole elements stay out; hidden choices and matrix rows inside represented questions retain an explicit marker.

Relationships / Conversation, Forum, Gather

Flat, but not context-free

Active records expose parent, container and depth as analytical fields. Required deleted ancestors become blank structural submissions rather than native Converlens threads.

Structured / Five roots

Use the common bounded contract

Quick Poll, Visioner, Question & Answer, Social Map and Budget conform complete source evidence into explicit analytical state.

Complete with a safety exception: omission is authoritative except when validated evidence marks an identity preserve-only because it cannot be represented safely. Prior native state is retained and a bounded warning is produced. Deleted relationship history enters only where an active descendant needs its parent chain resolved.

Bounded degradation: every admitted successful transfer becomes a private native file with source-version provenance. Excluded or failed intents become warnings; an existing verified file may be retained while a failed new file is omitted. Gather turns zero-byte or over-25-MiB images into bounded warnings, while malformed snapshot evidence is rejected.

07Authority And Consequences

Social Point owns whether a source record continues to exist. That is record-lifecycle authority, not merely ownership of selected fields, and its consequences extend to native resources attached to the canonical submission.

Removed with the source record

Dependent native state

  • Canonical submission
  • Attached comments
  • Activities and activity relationships
  • Analytical projections
  • Attached files and queued storage cleanup
Retained or detached

Surrounding native state

  • Contacts remain
  • Native replies are detached from the removed parent
  • Preserve-only identities retain prior state
  • Files outside the source-owned submission remain local
Catalogue authority: a validated complete catalogue can remove omitted Social Point-marked links, labels, spaces and projects. The policy for local child resources beneath a source-owned project must remain explicit.
Membership boundary: complete Social Point staff evidence reconciles managed workspace and project memberships. Activity participants, contacts, reactions, publication state and native thread membership remain outside the activity adapter contract.
